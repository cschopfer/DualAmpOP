Ce projet a un depot GIT local


Ajoute un fichier à la gestion de versions ou si modification avant commit:
git add mon_fichier.txt


Commit (enregistrer version)
git commit -m "Commentaire de version"

Si tu veux annuler les changements non commités :
git checkout -- mon_fichier.txt

Ajouter un TAG 
git tag -a v1.0 -m "Version 1.0"

Renommer un fichier
Ne pas renomment dans le Finder avant
git mv ancien_nom nouveau_nom


Déjà fait dans le projet:
git config --global cedric.schopfer "Cédric Schöpfer"
git config --global cedric.schopfer "cedric@digipict.ch"
